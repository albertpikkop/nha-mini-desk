NHA Mini Desk

Escribe o pega lo que quieres pedirle a la IA. La herramienta lo convierte en un prompt claro para ChatGPT, Gemini, Claude o la IA que uses.

Tus notas no se guardan en una base de datos.

Para qué sirve

Cuando pegas notas confusas en la IA, la respuesta puede salir bonita pero incompleta. Esta herramienta ordena tu pedido antes de enviarlo.

1 Elige el trabajo 2 Pega tus notas crudas 3 Copia el prompt a tu IA

1. Elige el trabajo

Primero selecciona qué quieres hacer. Después pega tus notas tal como están.

No tienes que ordenar nada antes.

La herramienta te ayuda a convertir una idea inicial, mensaje o notas de llamada en una instrucción clara para la IA.

Primero elige el trabajo y lo que quieres recibir. Luego puedes cargar un ejemplo para esa selección o pegar tus propias notas abajo.

El ejemplo aparecerá abajo en el cuadro de notas.

2. Pega tus notas crudas

Mensaje, llamada, correo, idea inicial o texto desordenado.

No las limpies. No las hagas bonitas. Si hay dudas, errores o datos faltantes, déjalos visibles.

4. Copia y usa

Este texto incluye reglas para ordenar la información y reducir inventos.

Qué haces después

Copia este prompt y pégalo en ChatGPT, Gemini, Claude o la IA que uses. La IA recibirá una mejor instrucción.
