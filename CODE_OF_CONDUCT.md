# Code of Conduct

Prompt Claro / Clear Prompt Builder is meant to be a welcoming learning project.

Please be respectful, constructive, and patient with contributors of different
technical levels, languages, and backgrounds.

We welcome:

- clear feedback
- small improvements
- translation help
- teaching examples
- thoughtful disagreement

We do not welcome:

- harassment
- insults
- spam
- discriminatory language
- attempts to shame beginners

Project maintainers may remove comments, issues, or pull requests that make the
project less safe or less useful for learners.
