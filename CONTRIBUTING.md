# Contributing

Thank you for helping improve Prompt Claro / Clear Prompt Builder.

This project is intentionally simple. Please keep it understandable for
students, non-technical users, and people who are still learning how to work
with AI.

## Good first contributions

- Fix a typo.
- Improve a translation.
- Add a better example.
- Improve mobile layout.
- Improve accessibility.
- Add a new output format.
- Make the prompt rules easier to understand.

## Local workflow

Open `index.html` in a browser.

If you have Node.js installed, you can run:

```bash
npm run check
```

## Pull request guidelines

- Keep changes small and easy to review.
- Explain what changed and why.
- Avoid adding dependencies unless there is a strong reason.
- Keep the tool browser-only unless the project roadmap changes.
- Do not add analytics, tracking, login, or backend storage without discussion.

## Translation guidelines

- Prefer simple language over perfect academic wording.
- Keep labels short enough for mobile.
- Avoid technical terms when a normal user-facing phrase works better.
- Preserve the privacy and human verification messages.

## Product principle

The tool should help a first-time user get a useful prompt in under one minute.
