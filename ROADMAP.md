# Roadmap

Prompt Claro / Clear Prompt Builder starts small on purpose.

## v0.1

- Static browser tool
- Spanish, English, Hindi, and Punjabi
- Example loading
- Local prompt generation
- Human verification checklist
- MIT open-source release

## Possible next steps

- More languages
- More example packs
- Better mobile polish
- Accessibility pass
- More output formats
- Local-only history option
- Export to `.md`
- Classroom exercise pack
- Prompt comparison examples
- Optional GitHub Pages mirror

## Not planned for now

- Login
- User accounts
- Backend database
- Required API keys
- Hidden analytics

The current purpose is education and adoption: help people understand how better
AI work starts before the AI response.
